# TOOLS.md

## Built-in Tools (always available)
- `memory_search(query)` — search prior session notes
- `memory_append(content)` — add a note to MEMORY.md
- `log(message, level)` — write to daily log
- `get_time()` — current date and time
- `read_user()` — load USER.md
- `read_file(path)` — read a file
- `write_file(path, content)` — write a file
- `shell_exec(cmd)` — run a shell command

## Custom Tools
None configured. Add your own in main.py.
